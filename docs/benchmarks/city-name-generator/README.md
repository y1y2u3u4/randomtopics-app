## Where we win

- 8 styles on one page (fantasy, dark fantasy, sci-fi, English, Spanish, German, Nordic, Italian)
- size filter village→capital
- population that matches the size
- one-line story hook per name
- root and ending from the same tradition
- lock and re-roll
- share link.
