## Where we win

- 10 styles
- All styles preview live as you type
- one tap copies with a “Copied ✓” check
- same text always gives the same output
- share link (?t=) opens the page with your text
- tabs jump to the 7 sibling text styles without retyping
- platform guide table (what works where)
- runs fully in the browser.
- Strength slider 1–10 (share link keeps it, ?k=).
