## Where we win

- Platform fit on every name (Instagram, TikTok, Roblox, Twitch, Xbox, Discord)
- mixable gaming/cute/cool/Instagram styles
- length + numbers + format (CamelCase, lowercase, under_score, dot.ted) filters
- character count
- lock and re-roll
- share link
- no ads in the result list.
