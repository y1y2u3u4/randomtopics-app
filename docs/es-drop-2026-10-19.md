# /es 首页点击下滑排查（2026-10-19）

GSC 上 /es 首页点击从 2,729 降到 2,172（两段 28 天对比）。结论：**不是排名下降**，是查询分流 + 英文首页抢了西语词。

## 数据

| 现象 | 之前 | 之后 | 说明 |
|---|---|---|---|
| /es 上 "*tema*" 类查询 点击 | 1,164 | 958 | 展示 6,868 → 7,512（↑），平均排名 4.8 → 4.1（↑） |
| "ruleta*" 类查询 落地 /es/spin-the-wheel | 65 | 261 | 意图更准的页接走了，属正常分流 |
| "temas random" 在 /es | 排名 1.9，128 点击 | 排名 1.3，81 点击 | 排名更好但点击下降：SERP 被 `/` 分走 |
| 英文首页 `/` 吃西语词 | — | "tema random" 103 点击（排名 1.9）、"temas aleatorios" 95、"generador de temas aleatorios" 77 | 这些点击本该落 /es |

## 原因

1. `/` 只有 canonical，没有 hreflang alternates；/es 有 en/es/x-default。Google 对西语用户没有可靠信号把 `/` 换成 /es，于是两个 URL 在同一西语 SERP 里互相分流。
2. 轮盘类意图被 /es/spin-the-wheel 正确接走（+196 点击），/es 首页少了这部分是好事。

## 建议

- **10/26 首页解冻后**：给 `/` 的 metadata 加 `alternates.languages`（en / es / x-default），与 sitemap 已声明的一致。只改 head，不动首屏和广告。预计把 `/` 上约 275 次西语点击还给 /es。
- 解冻前不动首页。
- 后续机会：葡语 "gerador de temas aleatórios" 目前排名 16（落 `/`），无 /pt 页面，可另开单评估。
- 土耳其语同理："rastgele konu seçici" 目前由 `/` 以排名 1.4 拿量；本 PR 新增 /tr 页面，上线后观察 2–3 周 `/` 与 /tr 的分流，若 /tr 接住再考虑在 `/` 加 tr hreflang。
