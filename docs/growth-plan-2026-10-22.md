# RandomTopics 4 周增长计划（2026-10-22 → 11-19）

目标：排名 + RPM 双涨。长期目标是每月 50 万点击、每月 $2,000 广告收入。

## 基线（GSC 9/22–10/19，28 天）

| 指标 | 数值 |
|---|---|
| 点击 | 57,481 |
| 曝光 | 906,438 |
| 平均排名 | 6.1 |
| 匿名词点击占比 | 40% |
| 广告收入 | 约 $200/月（7 万点击），RPM 约 $2.9/千点击 |
| 每次访问页数 | 约 1.6 |
| 页内广告位可见率 | 15% |

**实话：** 4 周内到不了 50 万/月（是现在的 8.7 倍）。

**本计划 4 周的现实目标：**
- 28 天点击 57k → 65–70k（+15–20%）
- 关键词池扩到现在的 2.5 倍（新页 + es/pt）
- 收入 RPM +30%

50 万要靠第 2–4 周开出来的新系列持续复利，再加首页 10/26 解冻后的改动。

**注意：** 11–30 位"差一点就上首页"的词只有约 4.4k 曝光，量太小。2.5 倍的池子必须靠新页面和新系列，不能靠推现有词。

## 第二部分：关键词池扩到 2.5 倍
