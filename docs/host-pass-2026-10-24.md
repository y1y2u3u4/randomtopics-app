# Host Pass — launch notes (2026-10-24)

Source: steward dispatch `2026-10-24-randomtopics-host-pass.md`. Features and pricing approved by the user on 10/24.

## What it is
A "Host mode" for party/classroom generators: one big prompt on the TV or projector, a round timer, and no repeats.
- Fullscreen presenter (`src/components/host/HostMode.tsx`, lazy): big text, dark/light theme, Space / → / Enter / PageDown = next, ← = back, Esc = close.
- Timer: Off / 15 / 30 / 60 s or custom (5–600 s), WebAudio beep + "Time!".
- No repeats per generator across sessions (`localStorage rt_host_seen_<generator>`), with a "Reset no-repeat" button.
- Ad-free while a pass is valid: `/api/speech/ad-entitlement` now checks `host_passes` after `classroom_purchases` (same flag, applies on next page load; the overlay covers ads anyway).
- Pages: charades, this-or-that, would-you-rather, truth-or-dare, question-of-the-day, icebreaker, debate. **Homepage not included** (frozen until 10/26) — add later.
- Charades already had a free "Fullscreen big text" button; Host mode adds the timer, cross-session no-repeat and ad-free.

## Traffic safety
- No change to title, H1, first-screen copy or direct-answer paragraphs. Free generation stays unlimited.
- Entry card (`HostPassEntry`) renders only after the 3rd successful generation in the tab session (`sessionStorage rt_gen_count`, shared across pages in the tab) or on a Checkout return. It is below the result, so no CLS on first paint.
- Prompt pools, Supabase and Stripe code load only when Host mode opens (`next/dynamic`, `ssr:false`, dynamic imports in `src/lib/host/pools.ts`).
- Free trial: 5 prompts per browser (`localStorage rt_host_trial_shown`), then the paywall.

## Pricing (Stripe live, USD only, adaptive pricing off, guest checkout)
| Plan | Price | Mode |
|---|---|---|
| pass30 (default, "Popular") | $4.99 / 30 days | one-time payment |
| monthly | $2.99 / month | subscription |
| yearly | $19.99 / year | subscription |

Prices are inline `price_data` in `src/lib/host/plans.ts` (no Stripe Price objects or env vars). Guests use Supabase anonymous sign-in, like the classroom/speech packs; anonymous buyers get a recovery link.
- Buying pass30 again stacks 30 days. A subscription can't be bought while one is active, and not while a pass30 is active (409).

## Relation to the classroom and speech packs
- One paywall at a time: the Host paywall shows only inside the presenter; the page itself shows at most the existing Classroom pack card (QOTD, debate) plus the Host entry card, which appears only after 3 generations. The three Host plans are radio options inside one panel, not three separate entries.
- Classroom pack and Host Pass both remove ads (either one is enough). Speech packs are unrelated (speech practice credits).
- Same Stripe account and customer per account (`speech_accounts.customer_id`), same webhook (`/api/speech/webhook`, `metadata.product = randomtopics_host_pass`).

## Backend
- Migration `supabase/migrations/20261024120000_host_passes.sql`: `host_passes` (RLS, service_role only), RPCs `grant_host_pass` (idempotent, stacks 30 days) and `sync_host_subscription` (ordered by Stripe event time).
- `POST /api/host/checkout` → Checkout session; `POST /api/host/status` → verifies the returned Checkout session (`?host_session=`) and reports access.
- Webhook: `customer.subscription.*` for Host subscriptions extends or ends access (active/trialing/past_due keep the period end; anything else expires now).

## Events (GA4 + Umami, same names; `tool_type: "host_mode"`)
host_entry_view, host_entry_click, host_trial_start, host_trial_end, host_paywall_view, host_plan_select (plan=pass30/monthly/yearly), host_checkout_start, host_purchase (only after the server confirms the grant; value in USD), host_session_start, timer_set (seconds), no_repeat_reset. GA4 only on the production host; `?usage_qa=1` → `qa_` names and no Umami.
