## Reproduced problems and changes

1. On the original built homepage, two clicks before clipboard completion made two provider calls and emitted two `copy_result` successes. The shared result actions now lock copy, group-copy and share together until completion, show a busy label, and keep Save usable. A changed result or unmounted card discards late completions. Failed copy still exposes exact selectable text and supports retry; cancelling native share remains neither success nor error. `aria-disabled` plus a synchronous guard retains keyboard focus; native disabled initially failed the existing focus regression and was corrected.
2. Home, wheel and Speech lost generated cards after leaving and using Back. Successful editorial draws now save a tab-local snapshot, scoped by route, locale, tool and preset. On ordinary return/reload, topic IDs, generation filters/count and used IDs restore without generating again. Snapshots expire after two hours; invalid/removed IDs and blocked storage are ignored. Explicit `#selected-topic` practice handoff continues to own its existing return card, so it does not receive another restored batch. No recordings, feedback, custom text, account state, checkout data or query strings are added to these snapshots.
3. On a 390×844 viewport, home and Speech showed filters instead of the generation action; wheel's button extended past the viewport. Home/Speech now put Generate first and disclose mobile filters on request, while retaining a second action after expanded filters. Desktop filters remain visible. Selected filters/count remain accessible. Wheel's mobile heading spacing is reduced; desktop spacing is preserved.
4. Wheel results now enter the existing local recent-topic library and expose the existing saved-library link after Save. Existing wheel action attribution is preserved.

Daily/random QOTD copy/save and the chosen-topic → free Speech entry were exercised on real built pages. QOTD's daily preference/date and random-mode behavior were not changed. This patch does not add a login wall or alter prices, subscription terms, free quota, recording, model providers, ad coverage or consent rules.

## Events and a defensible funnel

No new event names, same-meaning versions or GA configuration are added. Existing schema/transport fields remain `schema_version=1`, `environment`, `is_test`, plus the existing Speech measurement fields. All verification runs use localhost, synthetic data and blocked external/business traffic; no production analytics QA is sent.

| Boundary | Existing events | Meaning retained |
| --- | --- | --- |
| Deliberate draw | `generate_start`, `generate_success`, `spin_start`, `spin_success` | One actual draw; return/reload emits none of these. |
| Result use | `copy_result`, `copy_error`, `share_result`, `share_error`, `save_result`, `save_error` | Actual helper outcome; overlapping clicks are ignored. Cancel/unmounted completion does not fabricate success. |
| Generated-result use | `post_generate_copy`, `post_generate_share`, `post_generate_save` | Existing eligible generated-result context only. QOTD daily and wheel remain outside this strict series. |
| Visible actions | `post_generate_actions_view` | Existing ≥50% visible, focused foreground for one second; a click does not synthesize a view. |
| Saved continuation | `open_saved_topics` | Explicit navigation, including the new wheel link. |
| Practice continuation | Existing `handoff_*`, `speech_*` | Same-topic handoff and existing free practice sequence; no new synonym series. |

Result-action parameters remain the closed set `tool_type`, `content_source`, `result_type`, `action_surface`, `locale`; applicable additions are `copy_format=group_message`, `share_method=native|clipboard`, and `exposure_rule=visible_1s`. No editorial text, transcript, email, user identifier, attempt identifier or raw error is added to these action events.

For production evaluation, compare the same route/source, time range, environment and event definition after release. Exclude `is_test=true` and non-production environments; do not sum old/new aliases. A result-action rate based on aggregate events is diagnostic, not a user cohort conversion rate. Use ordered session/user funnel steps with a fixed denominator where the data supports them. Restoration can expose an existing result without a new draw, so do not assume every action must have a draw in the same pageview.

For Speech, feedback ready is not proof that feedback was visible; use the existing actual visible event. `speech_checkout_start` is intent, `speech_checkout_request` is a client request boundary, and redirect means the client received a usable redirect for its current identity. None proves a newly created provider session or a payment. Payment requires the existing trusted confirmed receipt/server boundary. Independent users on different events are not a cohort. No claim of improved conversion or revenue is made from these local tests.
